FINAL MODEL 2 WEBSITE

1. Install Python 3.12 if needed.
2. Open a terminal in this extracted folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python -m streamlit run streamlit_app.py

The browser opens automatically. Edit inputs and click Apply scenario to refresh.
Open the Model methods tab to read the model description.
Keep the terminal open. Press Ctrl+C to stop the website.
On Windows, py can replace python. See README.md for more instructions.

PUBLIC HOSTING
Upload the project to GitHub. On Streamlit Community Cloud, select
streamlit_app.py as the main file and Python 3.12 in advanced settings.
See README.md for deployment and expert-response storage instructions.
The original interface is still available with: python app.py

UPDATED OCTOBER 30
Updated habitat model includes EPA sewershed coverage. Annual transports scale
with reached-county burden and earlier nidi contribute transport origins.
Every scenario recalculates the landscape from year zero. Default year 20:
2,003 reached counties; 1,908 natural-only; 95 additional; 5 independent nidi.
Spread speeds use km/year: defaults 0 / 16 / 40 / 80; steps of 2 (0-400).
The map uses source colors, white-to-hue habitat shading, and nidus stars.
Transport distance now uses a shifted exponential with a 100-km minimum.
Edit Mean total transport distance (default 2,268 km) to update the curve,
central 95% trip-distance range, and derived long-haul share.
The Drop-off probability tab shows a separate map of cumulative deliveries.
Both maps share the selected year and county. No trucking-volume data are used.
